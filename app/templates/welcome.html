Workflow

  1. Basic data: schools, semesters, classes, subjects, students and teachers
  2. Teaching: create courses → enrol students → record attendance by course and date
  3. Exams: create an exam → set subject thresholds per grade → generate exam numbers
  4. Grades: enter scores online or import from the Excel template; query with filters
  5. Analytics: recalculate, then read class, grade and school-level statistics and charts
  6. Academic risk: flag students by failed subjects, absences, gap to class average and attendance
  7. Reports: one-click printable class report and Excel export
